ApplyFlow

Profile manager for academic job application auto-fill. Fill in once, reuse across Workday, Interfolio, AcademicJobsOnline, LinkedIn, Indeed, and generic portals.

Privacy: your data never leaves this browser. Everything on this page — including uploaded documents — is stored only in chrome.storage.local on this device. ApplyFlow has no server, no account, no analytics, and makes no network requests with your data.

Common application answers

Reusable answers for free-text questions that appear on many portals.

Education history

Most recent first — the top entry fills “highest degree”, “institution”, and “graduation date” fields. Add as many entries as you need.

References

Reference-letter writers. Portals that ask for references typically want name, title, email, and phone for each.

EEO / demographic self-identification Optional

Voluntary self-ID answers common on US academic HR portals (Workday especially). Leave blank and ApplyFlow will simply skip these questions. Answering is always voluntary — and like everything else here, these answers never leave your browser.

ApplyFlow matches these answers against dropdown options and radio-button labels by text similarity, then highlights its choice for your review.

Document store

Upload each document once. The file is stored locally as base64 and its text is extracted (best-effort for PDF) so the extension can inject the file into upload slots or paste the text into statement textareas. Plain-text files (.txt/.md) extract perfectly; for PDF/DOCX you can edit the extracted text below.

Cover letter templates

Named templates with placeholders — {{position}}, {{department}}, {{university}}, {{date}} — that are substituted from the detected job context when you fill a page or copy a letter. The first template is the default. Optionally attach a PDF/DOCX version for upload slots.

Export / import

Your whole profile — including documents — exports to a single .json file. Keep it somewhere safe; it contains everything you entered, including EEO answers.

ApplyFlow stores everything in your browser’s local extension storage. No servers, no tracking, no remote code. Review-first design: the extension never submits a form for you.
